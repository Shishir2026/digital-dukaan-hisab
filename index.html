Firebase security rules

In Firestore → Rules, use this rule so each signed-in user can access only their own record:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/appData/{docId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}

This app is a starter project, not a regulated accounting system. Verify records and keep regular backups.
